# aniML overview

The aniML guide and software package is intended to provide a complete accelerometer-based behaviour classification pipeline readily able to be applied to any dataset with minimal programming input. While there are options for extensive customisation if desired, the aniML system was designed for ecologists with limited experience in R and no experience with machine learning. Additionally, the system is optimised for small, messy, incomplete, realistic ecological datasets.


The following guides introduce the philosophy and pragmatics of behavioural classification with aniML. The guides are intended to give a sufficient overview of the goals and pitfalls of behaviour classification machine learning and the practical usage of the aniML package without being exhaustive. Two worked examples have been provided.
