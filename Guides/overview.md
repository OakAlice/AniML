# aniML overview

The purpose of the aniML guide is to provide a complete and well-validated accelerometer-based behaviour classification pipeline readily able to be applied to any dataset with minimal programming input. Unlike other available minimum-viable packages, the aniML approach encompasses the complete end-to-end requirements for any standard project with integrated code to guide the ecologist through behaviour selection, preprocessing, optimised classification, post-processing, logic-checking, and some basic ecological interpretations with an explicit focus on small datasets which may perform poorly with more traditional approaches. This workflow takes raw multi-axis accelerometer data and returns time-labelled behaviour predictions. 

The following guides introduce the philosophy and pragmatics of behavioural classification with aniML.
