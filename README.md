# aniML

The **aniML** guide and software package is intended to provide a complete accelerometer-based behaviour classification pipeline readily able to be applied to any dataset with minimal programming input. While there are options for extensive customisation if desired, the aniML system was designed for ecologists with limited experience in R and no experience with machine learning. Additionally, the system is optimised for small, incomplete, realistic ecological datasets, with compensations in place for the limitations and complications that arise from such data.
